3. Роадмап разработки (по этапам)
Этап 0: Прототип механики (1–3 дня)
Цель: одна сцена, один управляемый объект, одна механика.

Реализуй GameScene:

загрузка одного спрайта игрока

управление (стрелки/WASD)

простая физика (Arcade Physics достаточно для большинства 2D)

одна механика: прыжки, стрельба, сбор монет и т.п.

Не делай меню, настройки, сохранения — только «играбельный кусок».

Полезные темы для поиска:
"Phaser 3 TypeScript player movement tutorial", "Phaser Arcade Physics TypeScript example".

Этап 1: Базовый игровой цикл (3–7 дней)
Цель: полноценный цикл «старт → игра → проигрыш/победа → рестарт».

Добавь:

MenuScene: кнопка «Start», возможно «How to play».

Условия победы/поражения и переход между сценами:

ts
this.scene.start('GameScene');
this.scene.start('MenuScene');
Простейший UI: счёт, жизни (можно через UIScene как отдельную сцену поверх игровой).

Этап 2: Контент и полировка (1–3 недели)
Цель: сделать игру «законченной» для itch.io.

Уровни / прогрессия:

несколько уровней или усложнение со временем

враги, препятствия, бонусы

Ассеты:

спрайты, анимации (anims.create, play)

звуки и музыка (загрузка в PreloadScene, воспроизведение в сцене)

Баланс:

скорость, урон, частота спавна врагов и т.д.

«Game feel»:

партиклы, тряска камеры, простые эффекты смерти/удара.

Этап 3: Сборка под HTML5 и тесты в браузере
Цель: получить готовую папку для загрузки на itch.io.

В терминале проекта:

bash
npm run build
После этого появится папка dist/ (или build/, зависит от шаблона) с:

index.html

JS-бандлами

ассетами

Проверь локально:

Открой dist/index.html через локальный сервер (не просто файл из файловой системы). Например:

bash
npx vite preview
# или
npx serve dist
Пройди игру от начала до конца, проверь:

работу на разных размерах окна

отсутствие ошибок в консоли

адекватность управления с клавиатуры (и тача, если нужно).
