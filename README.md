IDEA : SDU's Map + 2D + Stud sim in gta 1 or 2 style

Ты — опытный геймдев-разработчик на Phaser 3 + TypeScript + Vite.
Мне нужно собрать MVP 2D-игры с видом сверху (top-down) по следующей структуре проекта:

my-game/
  src/
    main.ts
    scenes/
      BootScene.ts
      PreloadScene.ts
      MenuScene.ts
      GameScene.ts
      UIScene.ts
    entities/
      Player.ts
      Enemy.ts
    config/
      gameConfig.ts
    utils/
      input.ts
      math.ts
  public/
    assets/
      sprites/
      audio/
      maps/
  index.html
  package.json
  tsconfig.json
  vite.config.ts

Твоя задача:
1. Дать полный код для каждого файла из этой структуры, чтобы получилась рабочая MVP-игра:
   - Игрок управляется клавишами WASD или стрелками.
   - Есть простая арена (фон или тайловая карта).
   - Есть 1 тип врага, который медленно движется к игроку.
   - При касании врага игрок «умирает» — сцена перезапускается или показывается простой Game Over.
   - Есть простой счёт (например, время выживания в секундах).
   - Есть минимальное меню: название и кнопка/клавиша для старта.
   - Есть прелоадер, который загружает спрайты игрока и врага.

2. Для каждого файла указать:
   - полный путь (например: `src/scenes/GameScene.ts`)
   - полный код файла.

3. Использовать TypeScript с типами, без `any` там, где это легко.
4. Предположить, что спрайты `player.png` и `enemy.png` уже лежат в `public/assets/sprites/`.
5. Сделать код максимально понятным, с короткими комментариями на русском, чтобы новичок мог разобраться.
6. В конце кратко описать, как запустить проект:
   - какие команды выполнить (`npm install`, `npm run dev` и т.д.)
   - как собрать билд для itch.io (`npm run build`).
